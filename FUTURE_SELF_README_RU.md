# FUTURE SELF — исходная версия + обновлённая карта и backend-заготовка

## Что уже сделано во frontend
- Сохранена исходная структура приложения и исходная розово-молочная визуальная тема.
- На карту можно загружать несколько фотографий с телефона, добавлять готовые образы и текстовые блоки.
- Элементы карты можно перетаскивать, выбирать, менять ширину, редактировать подпись и удалять.
- Экспорт PNG сохранён.
- AI-чат отправляет запрос на защищённый endpoint `/api/ai/chat`; история последних сообщений передаётся серверу.
- Кнопка PRO вызывает `/api/payments/create-invoice` и открывает Telegram invoice, если backend настроен.
- Панель ADMIN использует серверные endpoints. Сервер назначает ADMIN только Telegram ID из `ADMIN_TELEGRAM_ID` (по умолчанию 7738464404).

## Важно: это ещё не опубликованный production-сервис
Frontend и серверный исходный код подготовлены, но backend не развёрнут и секреты не добавлены. Поэтому AI, Stars-платежи и админ-панель не заработают в живом Telegram, пока сервер не будет размещён и подключён к домену.

## Развёртывание backend
Нужен Node.js 20+ хостинг, поддерживающий постоянный процесс и запись SQLite-файла. Не GitHub Pages.

1. Скопировать `.env.example` в `.env` и заполнить `BOT_TOKEN`, `GEMINI_API_KEY`, `BOT_WEBHOOK_SECRET`. Никогда не публиковать `.env` и не отправлять токены в чат.
2. Выполнить `npm install`, затем `npm start`.
3. Разместить frontend `index.html` на HTTPS-хостинге и настроить reverse proxy `/api/*` на этот Node-сервер (или разместить frontend и API на одном домене).
4. Установить webhook Telegram на `https://ВАШ-ДОМЕН/telegram/webhook`, передав тот же `BOT_WEBHOOK_SECRET` как `secret_token`.
5. В BotFather указать HTTPS URL frontend как Main App / Menu Button URL.

## Что нужно проверить перед продажей подписки
- Telegram Stars subscription period — 30 дней; проверить фактическое поведение продления/отмены в тестовом окружении.
- Добавить пользовательский экран управления подпиской и поддержку `subscription_period`/`is_recurring`/`is_first_recurring` из обновлений Telegram, а также обработку возвратов и спорных платежей.
- Подключить резервное копирование БД, мониторинг, лимиты AI, политику конфиденциальности и условия подписки.
- Проверить Telegram initData на production домене и пройти тестовую оплату.

## Безопасность
- AI API key и Bot token используются только на сервере.
- Сервер проверяет подпись Telegram initData и не доверяет роли, присланной браузером.
- ADMIN проверяется на сервере по `ADMIN_TELEGRAM_ID`.
- Не загружать `.env`, SQLite DB и секреты в публичный GitHub.
